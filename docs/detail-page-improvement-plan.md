# 詳細ページの改修と確認の進め方

## 対象と状況

2026年11月2日時点の対象はイベント863件、遊び場385件の計1,248件。当初、見どころを個別編集したページは17件。画像が表示されないページはイベント655件、遊び場292件だった。現在の件数は監査ツールで再集計する。画像の有無は表示候補の有無であり、実写・正常表示・利用許諾の確認を意味しない。既存画像も個別に確認する。

全件共通の表示改善と、個別の情報・写真の調査は別に進める。共通表示を適用しただけでは、内容の調査完了とは数えない。

## 進め方

1. `python3 tools/audit_detail_pages.py --csv > /tmp/detail-review.csv` で対象一覧を作る。開催状況はDBの日付からの目安で、終了日のないイベントなどは公式情報で確認する。
2. 開催前・開催中のイベントと常設の遊び場を優先し、開催終了イベントも記録として残す。開催日、会場、料金、対象、予約、休業・開催条件、公式URLを一次情報と照合する。公式案内が消えている場合や情報が特定できない場合は未確認として残す。
3. そのページ固有の体験や魅力を根拠に沿って書き、訪問前に必要な情報を整理する。過ごし方の提案は一例と明示し、所要時間・設備・開催内容を推測で断定しない。
4. 写真は対象との一致、撮影時期、使用条件、出典・クレジットを確認する。条件不明なら公開候補として扱わず、使用可能な写真がないことを未完了として記録する。昔の写真や会場の参考写真はその旨を表示する。
5. 100件程度を上限に区切り、文章・出典・画像・スマートフォン表示を確認する。全対象の改修と最終確認が終わった後にまとめて本番公開する。`data/detail-review.json` に種別とIDごとに確認日、出典、内容・画像それぞれの確認結果を残し、再実行した一覧と照合する。過去の編集済みページも確認記録がない場合は未記録として扱う。

## 完了条件

全ページについて、内容・出典の確認結果と写真の確認結果が記録され、根拠がある内容のみ公開されていること。ページの個別編集件数や画像の表示件数だけでは完了としない。公開済み情報も開催期間や施設情報の更新に応じて再確認が必要。
